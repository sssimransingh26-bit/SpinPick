# SpinPick — Decision Wheel

SpinPick is a simple, interactive web application that helps users make random decisions. Add your own options, spin the wheel, and let it select a result.

## Features

- Interactive spinning wheel with colorful segments
- Add custom options
- Remove options from the list
- Randomly select a winner
- Display the selected result
- Spin again or reset the wheel
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas (if used in the implementation)

## Getting Started

No additional installation or build tools are required.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Add your options and click the Spin button.
